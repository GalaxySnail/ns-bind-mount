# ns-bind-mount
A bind-mount helper for existing mount namespaces, inspired by bubblewrap and nsenter.

## AI Disclaimer

This repo is mostly generated by LLMs.

## Usage

```
Usage: ns-bind-mount <bind|ro-bind|dev-bind> <pid> <srcpath> <dstpath>

Modes:
  bind      Bind mount srcpath on dstpath (nosuid, nodev, recursive)
  ro-bind   Read-only bind mount srcpath on dstpath (ro, nosuid, nodev, recursive)
  dev-bind  Bind mount srcpath on dstpath allowing devices (nosuid, recursive)
```

The dstpath should be an absolute path.
